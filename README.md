Vintage Delight is a culinary-focused mod that enriches your farming and cooking experience in the game. As an addon to the Farmer's Delight mod, it introduces a variety of new crops, foods, and crafting processes mainly centered around the new block, the Fermenting Jar.

## Community Maintenance Notice

This workspace is an unofficial community maintenance and porting workspace. The upstream project metadata declares the mod license as MIT, and this fork keeps the MIT license text in `LICENSE` for clarity.

The `0.1.6` baseline was restored by comparing the public source tree with a locally owned `0.1.6` release jar. See `PORTING_NOTES.md` for attribution, distribution, and porting notes.
